装插件等于装代码

主题色
改的是整个界面的主色（按钮、选中态、链接等）。所有颜色都由它派生，不用逐个调。

行为与安全

开启后 shell 不再只限只读命令，模型可以执行任意命令（仍会问你一次）。只建议在沙箱或虚拟机里开。

联网搜索

打开后模型多出两个工具：web_search（搜关键词，返回标题 / 链接 / 摘要）和 web_fetch（把某个网页抓成正文）。查版本号、报错含义、最新文档这类它「记不准」的事时很有用。
关掉后这两个工具不会出现在模型的能力列表里——它是根本不知道有这回事， 而不是试了再失败。完全在内网干活时建议关掉，能省下几轮白跑的工具调用。

上下文与压缩

由 context-compact 插件实现：把较早的历史交给模型总结成一段摘要， 用摘要替换那一段，最近几轮原样保留。关掉它就只能靠模型的窗口硬扛。 默认是手动压缩：输入框下方有个「压缩上下文」按钮，也可以发 /compact。 压缩会改写对话历史，自动压有时会把你正在回看的旧消息折掉，所以默认交给你决定。 想让它自己盯着用量就打开这个开关。

要让 agent 不再询问吗？

    

    

      

        切到「完全权限」之后，agent 改写文件、执行命令、删除内容都**不会再问你**——
        包括工作目录以外的路径。只有少数硬黑名单（rm -rf /、git push --force 这类）

        建议只在「我就在旁边看着、而且这批操作我本来就要做」的时候用；平时用「工作区内执行」更稳。
