# 设置里有什么


设置浮层（顶栏「设置」按钮打开）是所有配置的入口：

| 视图 | 内容 |
|---|---|
| **模型与 API** | 服务商、接口地址 baseUrl、模型、API Key、流式输出、测试连接；GitHub Token |
| **插件管理** | 已装插件的启用 / 禁用 / 卸载、重载、生成插件骨架；下方是当前可用的工具清单 |
| **插件市场** | 从 GitHub 搜索并安装插件 |
| **外观** | 浅色 / 深色切换；**主题色色板**（8 个颜色） |
| **行为与安全** | 最大工具调用轮数、免确认放行的工具名单、放开 shell 限制 |
| **关于** | 版本与环境信息、目录（可直接打开）、当前生效的完整配置 |

模型设置和行为设置**各自有保存按钮**——只提交这一块的内容。这样不会出现「改了个轮数，结果把 API Key 也一起覆盖了」这种意外。

> 只是**换个模型**的话不用进设置：输入区左下角有个模型按钮，点开选一下立刻生效（见 [换模型](./ui.md#换模型-推理等级输入区左下角就有按钮)）。顶栏原来的模型胶囊已经去掉——模型显示只留输入区这一处，避免重复入口。

### 主题与主题色

- **默认浅色**（白底）。改主题有两条路：顶栏的「设置」→「外观」里选浅色/深色，或者按 `Ctrl + ,` 打开设置
- **主题色**有 8 个选择：青 / 蓝 / 靛 / 紫 / 粉 / 红 / 橙 / 绿。点一下整个界面的主色就换了（按钮、选中态、链接、输入框聚焦边框全跟着变）
- 主题和主题色都会记住，下次打开还是你选的那套
- 第一次打开时主题跟随系统（系统深色就用深色）

想加自己的颜色，往 `web/app.js` 的 `ACCENTS` 数组加一行即可。每个颜色要写**两套取值**：

```js
{ key: 'blue', name: '蓝',
  light: ['#2563eb', '#ffffff', '#1d4ed8'],   // 浅色主题下用
  dark:  ['#60a5fa', '#0b1220', '#2563eb'] }, // 深色主题下用
//       主色       压在主色上的字色   加强版（logo/头像用）
```

为什么必须分两套：`#2563eb` 在白底上很清楚，放到深色底上就发闷；反过来 `#60a5fa` 在白底上又太浅看不清。这是配色上绕不过去的。

> 两个细节都做了处理：主题色在页面渲染**之前**就设好了（`web/index.html` 里 `<link rel="stylesheet">` 上面那段内联脚本），否则打开程序会先闪一下默认青色；切换浅色/深色时主色会**重新取值**，不会把「白底专用」的颜色留在深色界面上。
