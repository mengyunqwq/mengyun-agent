# 桌面程序


### 它是什么

不是「网页套壳」，而是一个正常的桌面应用：

- **原生窗口**，有标题栏、能最小化、能记住你上次的窗口大小和位置
- **中文菜单栏**：文件 / 编辑 / 视图 / 帮助，带常用快捷键
- **独立进程**：关掉命令行窗口，程序照常在跑
- **单实例**：重复双击只会聚焦已有窗口，不会开出第二份
- **外链走系统浏览器**：点文档链接不会把应用窗口「拐跑」
- **端口被占用会自动换一个**，不会报错退出

### 无边框窗口

界面用的是 `frame: false`（无边框窗口），标题栏由页面自己画。原因很实际：

Windows 会给每个窗口外面画一圈浅色边框和阴影，**深色界面下那圈边特别显眼**——这就是你之前看到的「白边」。去掉系统边框之后：

- 那圈边彻底没有了
- 切到深色主题时，窗口边框和阴影会跟着一起变深，不会出现"深色界面配一圈浅边"的割裂感
- 顶栏空白处仍然可以拖动窗口（按钮区域除外）

### 菜单能干什么

| 菜单 | 项目 |
|---|---|
| 文件 | 新建会话（`Ctrl+N`）、打开工作目录、打开会话记录目录、打开插件目录、退出 |
| 编辑 | 撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选 |
| 视图 | 刷新界面（`Ctrl+R`）、缩放（`Ctrl+±`）、全屏、开发者工具（`Ctrl+Shift+I`） |
| 帮助 | 打开文档、显示服务地址、关于（含版本和环境信息） |

### 自检

窗口白屏、主题不对、桌面功能没生效？一条命令定位：

```powershell
mya desktop --selftest
```

它会**真的创建一个窗口**、加载页面、执行 JS 检查，然后逐项告诉你（下面是节选）：

```

  Electron 44.4.4 / Chromium 152.0.7977.130

✓ 窗口标题：梦云 Agent
✓ preload 桥已注入（window.myaDesktop）
✓ 对话容器已渲染
✓ 输入框已渲染
✓ 会话列表已加载（1 个）
✓ 页面已识别为桌面模式
✓ 默认主题是浅色（data-theme=light）
✓ 界面确实是白底（亮色像素占 98%）
✓ 启动流程走完了（当前步骤：done）
✓ 设置平时是收起的，不占页面
✓ 点「设置」按钮能把设置浮层打开
✓ 设置里分成了 6 个视图
✓ API 接入收进了设置里
✓ 关掉之后设置不再占页面（display=none）
✓ 主题色色板渲染出来了（8 个颜色）

✓ 自检结束后主题色已还原（violet → teal）
✓ 深色下界面确实变暗（亮色像素占 0%）
✓ 能切回浅色（外观里选浅色）
✓ 界面能访问本地接口（/api/info）
✓ 当前模型：deepseek/deepseek-chat
```

几点说明：

- 涉及主题的检查**不是查 DOM 属性就算完**，而是截图并采样像素——只有像素是白的，才能证明用户看到的真的是白底。自检还会存两张截图（`selftest-light.png` / `selftest-dark.png`）方便你直接看。
- 加了 `data-boot` 启动标记：启动流程有好几个 `await`，任何一步抛错都会让后面的步骤静默不执行、界面却「看起来还行」。有了这个标记，一眼就能看出卡在哪一步。
- 自检**不会动你的配置**——它会记住你原来的主题和主题色，检查完再还原。
- 上下文用量和思考块也会验：给用量圆环注入一个假的用量，确认**圆环真的按比例画出进度（周长反推）、接近上限会变色告警、而且鼠标放上去真的会展开气泡**；思考块则验证折叠/展开两种状态下的显示，以及标题里有没有耗时和 token 数。

调试用 `mya desktop --dev` 打开开发者工具。

> 页面里还有一条**默认关闭**的交互追踪（`web/app.js` 的 `traceStart`）：自检会给页面地址加上 `?myaTrace=1`，把最近的点击记下来。起因是设置浮层曾经莫名在启动时就是打开状态——界面和 console 都看不出是谁点的，只能靠轨迹定位。如果你也遇到「某个 UI 状态来路不明」，这是最省事的查法。

### 应用图标

图标不是图片文件，而是**用代码画的**——因为要同时提供窗口、任务栏、exe、网页标签页四种用途，尺寸格式各不相同（16/24/32/48/64/128/256）。

```powershell
npm run icon      # 重新生成图标
```

| 产出 | 用途 |
|---|---|
| `build/icon.ico` | 窗口、任务栏、打包后的 exe（内含 7 个尺寸） |
| `build/icon.png` | 1024×1024 源图，打包工具的输入 |
| `web/icon.png` | 浏览器标签页图标 |

想换配色，改 `desktop/make-icon.js` 顶部的 `COLORS`；想换成自己的图，直接拿一张 1024×1024 的 PNG 覆盖 `build/icon.png` 即可。

> 生成器是纯 Node 手写的 PNG / ICO 编码器（`desktop/make-icon.js`），没引任何图形库。想了解 PNG 和 ICO 的文件格式，这个文件本身就是个能跑的参考——里面有完整的 chunk 结构、CRC32 计算、以及「ICO 里的 BMP 为什么高度要写两倍」这类细节。
